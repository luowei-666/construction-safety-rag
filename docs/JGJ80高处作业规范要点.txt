建筑施工高处作业安全技术规范 JGJ80-2016 要点
（行业标准《建筑施工高处作业安全技术规范》JGJ80-2016，住房和城乡建设部2016年7月9日发布，2016年12月1日实施；本文档为核心条款摘录，供智能问答系统使用）
来源：上海市住房和城乡建设管理委员会公开文件 https://zjw.sh.gov.cn/cmsres/dd/dd2874d657124e648b54c66a113fb0b1/2b641c95070e63127349d11cc3109bc6.pdf

一、适用范围与基本概念
1. 高处作业：在坠落高度基准面2m及以上有可能坠落的高处进行的作业。
2. 临边作业：在工作面边沿无围护或围护设施高度低于800mm的高处作业，包括楼板边、楼梯段边、屋面边、阳台边、各类坑、沟、槽等边沿的高处作业。
3. 洞口作业：在地面、楼面、屋面和墙面等有可能使人和物料坠落，其坠落高度大于或等于2m的洞口处的高处作业。
4. 悬空作业：在周边无任何防护设施或防护设施不能满足防护要求的临空状态下进行的高处作业。

二、强制性条文（必须严格执行）
1. 第4.1.1条：坠落高度基准面2m及以上进行临边作业时，应在临空一侧设置防护栏杆，并应采用密目式安全立网或工具式栏板封闭。
2. 第4.2.1条：洞口作业时，应采取防坠落措施。
3. 第5.2.3条：严禁在未固定、无防护设施的构件及管道上进行作业或通行。
4. 第6.4.1条：悬挑式操作平台的搁置点、拉结点、支撑点应设置在稳定的主体结构上，且应可靠连接；严禁将操作平台设置在临时设施上。
5. 第8.1.2条：建筑施工安全网设置应符合规定。

三、基本规定
1. 高处作业施工前，应对安全防护设施进行检查、验收，验收合格后方可进行作业，并应做验收记录。
2. 高处作业施工前，应对作业人员进行安全技术交底并记录；应对初次作业人员进行培训。
3. 高处作业人员应按规定正确佩戴和使用相应的安全防护用品、用具。
4. 高处作业所用的物料应堆放平稳，不得随意放置或向下丢弃；传递物料时不得抛掷。
5. 遇有6级及以上强风、浓雾、沙尘暴等恶劣气候，不得进行露天攀登与悬空高处作业。
6. 安全防护设施宜采用定型化、工具化设施，防护栏应为黑黄或红白相间的条纹标示。

四、临边与洞口作业
1. 坠落高度基准面2m及以上临边作业，应在临空一侧设置防护栏杆，并用密目式安全立网或工具式栏板封闭。
2. 楼梯口、楼梯平台和梯段边应安装防护栏杆。
3. 建筑物外围边沿处，没有设置外脚手架的工程应设置防护栏杆；有外脚手架的工程应采用密目式安全立网全封闭。
4. 洞口防护分类：
   - 竖向洞口短边边长小于500mm：采取封堵措施；大于等于500mm：临空一侧设置高度不小于1.2m的防护栏杆并封闭、设置挡脚板；
   - 非竖向洞口短边边长25mm~500mm：采用承载力满足要求的盖板覆盖，防止移位；
   - 500mm~1500mm：采用盖板覆盖或防护栏杆等措施，固定牢固；
   - 大于等于1500mm：洞口作业侧设置高度不小于1.2m的防护栏杆，洞口采用安全平网封闭。
5. 电梯井口应设置防护门，高度不应小于1.5m，防护门底端距地面高度不应大于50mm，并应设置挡脚板。
6. 洞口盖板应能承受不小于1kN的集中荷载和不小于2kN/m²的均布荷载。

五、防护栏杆构造
1. 防护栏杆应由横杆、立杆及挡脚板组成。
2. 应为两道横杆：上杆距地面高度1.2m，下杆设置在上杆和挡脚板中间；防护栏杆高度大于1.2m时应增设横杆，横杆间距不应大于600mm。
3. 立杆间距不应大于2m；挡脚板高度不应小于180mm。
4. 防护栏杆在上下横杆和立杆任何部位处，均应能承受任何方向1kN的外力作用。

六、攀登作业
1. 登高作业应借助施工通道、梯子及其他攀登设施和用具，不得攀爬脚手架杆件或非专用设施。
2. 同一梯子上不得两人同时作业；脚手架操作层上严禁架设梯子作业。
3. 使用单梯时梯面应与水平面成75°夹角，踏步不得缺失，不得垫高使用。
4. 固定式直梯攀登高度超过3m时宜加设护笼；超过5m时应设置梯间平台。
5. 深基坑施工应设置扶梯、人坑踏步及专用载人设备或斜道等设施；作业人员严禁沿坑壁、支撑或乘运土工具上下。

七、悬空作业
1. 悬空作业的立足处应设置牢固，并配置登高和防坠落装置和设施。
2. 严禁在未固定、无防护设施的构件及管道上进行作业或通行。
3. 高处作业不得使用座板式单人吊具，不得使用自制吊篮。
4. 浇筑高度2m及以上的混凝土结构构件时，应设置脚手架或操作平台。
5. 屋面作业：坡度大于25°的屋面上作业且无外脚手架时，屋檐边应设置不低于1.5m高的防护栏杆并密目式安全立网全封闭；不得在轻质型材上行走。

八、操作平台
1. 移动式操作平台：面积不宜大于10m²，高度不宜大于5m，高宽比不应大于2:1，施工荷载不应大于1.5kN/m²；移动时操作平台上不得站人。
2. 落地式操作平台：高度不应大于15m，高宽比不应大于3:1；不得与脚手架连接。
3. 悬挑式操作平台：严禁设置在临时设施上；悬挑长度不宜大于5m；应设置4个吊环，吊运时应使用卡环，不得使吊钩直接钩挂吊环。

九、交叉作业
1. 垂直空间贯通状态下，可能造成人员或物体坠落的立体作业，处于坠落半径范围内应设置安全防护棚等防护设施。
2. 立体交叉作业时，下层作业位置应处于上层作业坠落半径之外；否则应设置安全防护棚。
