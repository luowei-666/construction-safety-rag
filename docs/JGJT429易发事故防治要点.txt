建筑施工易发事故防治安全标准 JGJ/T429-2018 要点
（行业标准《建筑施工易发事故防治安全标准》JGJ/T429-2018，住房和城乡建设部2018年2月14日发布；本文档为核心条款摘录，供智能问答系统使用）
来源：公开标准文件 http://jgjl.com/static/upload/file/20210330/1617085916187362.pdf

一、标准定位
本标准针对建筑施工中易发、频发的事故类型（坍塌、高处坠落、物体打击、机械伤害、触电、起重伤害及其他易发事故），规定了防治措施，适用于房屋建筑工程和市政工程施工中的易发事故防治。

二、易发事故类型定义
1. 坍塌：基坑、边坡、桩孔、临时设施、钢筋、模板、预制构件等在外力、地基不均匀沉降作用下，超过自身承载极限或因结构稳定性破坏而造成的伤害事故。
2. 高处坠落：在高处作业过程中人员坠落而造成的伤害事故。
3. 物体打击：物体在重力或其他外力作用下产生运动，打击人体而造成人身伤害事故。
4. 机械伤害：机械设备运动（静止）部件、工具、加工件直接与人体接触引起的夹击、碰撞、剪切、卷入、绞、碾、割、刺等伤害。
5. 触电：电流流经人体或动物体，使其产生病理生理效应而造成的伤害。
6. 起重伤害：各种起重作业中发生的重物（包括吊具、吊重或吊臂）坠落、夹挤、物体打击等造成的伤害。

三、基本规定
1. 施工单位应根据工程特点和易发事故类型，制定针对性的防治措施，并纳入施工组织设计或专项施工方案。
2. 易发事故防治应坚持"预防为主"的原则，强化事前控制、过程监管。

四、坍塌防治要点
1. 基坑工程：基坑支护施工、使用时间超过设计使用年限时，应进行基坑安全评估，必要时应采取加固措施。
2. 基坑施工应按设计规定的顺序和参数进行开挖和支护，并应分层、分段、限时、均衡开挖，严禁超挖。
3. 基坑顶边缘1m范围内禁止堆放材料、设备等荷载。
4. 各类施工机械距基坑边缘、边坡坡顶、桩孔边的距离，应根据设备重量、支护结构、土质情况按设计要求确定，且不宜小于1.5m。
5. 高度超过2m的竖向混凝土构件钢筋绑扎过程中及绑扎完成后，在侧模安装完成前，应采取有效的侧向临时支撑措施。

五、高处坠落防治要点
1. 绑扎钢筋和安装钢筋骨架需悬空作业时，应搭设脚手架和上下通道，不得攀爬钢筋骨架。
2. 绑扎圈梁、挑梁、挑檐、外墙、边柱和悬空梁等构件的钢筋时，应搭设脚手架或操作平台。
3. 绑扎立柱和墙体钢筋时，不得站在钢筋骨架上或攀登骨架作业。
4. 洞口、临边作业应按高处作业规范设置防护栏杆、盖板、安全网等防护设施。
5. 作业人员应正确佩戴安全帽，高处作业应系挂安全带，做到高挂低用。

六、物体打击防治要点
1. 高处作业的物料应堆放平稳，工具应随手放入工具袋；拆卸下的物料、余料应及时清理运走，不得随意向下丢弃或抛掷。
2. 立体交叉作业时，处于坠落半径范围内的通道、作业区应设置安全防护棚。
3. 进入施工现场应正确佩戴安全帽。

七、机械伤害防治要点
1. 机械设备应有齐全有效的安全防护装置，传动部位应有防护罩。
2. 机械设备操作人员应经过培训考核合格后上岗，严禁无关人员操作机械设备。
3. 机械运转时，严禁进行维修、保养、清理等作业；停机维修时应切断电源并挂牌警示。

八、触电防治要点
1. 配电系统应设置配电柜或总配电箱、分配电箱、开关箱，实行三级配电；除在末级开关箱内加装漏电保护器外，还应在总配电箱加装一级漏电保护器，总体形成两级保护。
2. 配电柜应装设隔离开关及短路、过载、漏电保护电器，电源隔离开关分断时应有明显的可见分断点。
3. 电缆线路应采用埋地或架空敷设，严禁沿地面明设、拖地敷设。
4. 电焊机应设置二次侧触电保护装置，一次侧电源线长度不宜大于5m。

九、起重伤害防治要点
1. 起重吊装作业应编制专项施工方案，并按规定进行审批；超过一定规模的应组织专家论证。
2. 起重机械应有齐全有效的限位、保险装置，并经检验检测合格、办理使用登记后方可使用。
3. 起重作业应设专职指挥人员，严禁超载、斜拉斜吊；作业人员严禁在吊物下方停留或通过。
4. 塔式起重机、施工升降机等应按规定进行安装、拆卸和定期检查维护。
