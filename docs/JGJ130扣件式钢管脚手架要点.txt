建筑施工扣件式钢管脚手架安全技术规范 JGJ130-2011 要点
（行业标准《建筑施工扣件式钢管脚手架安全技术规范》JGJ130-2011，住房和城乡建设部发布；本文档为核心条款摘录，供智能问答系统使用）
来源：济南市住房和城乡建设局公开文件 http://jncc.jinan.gov.cn/module/download/downfile.jsp?classid=0&filename=31240ead62384ec5ad66ab07f7cc151a.pdf

一、适用范围与基本规定
1. 本规范适用于房屋建筑工程和市政工程等施工用落地式单、双排扣件式钢管脚手架、满堂扣件式钢管脚手架、型钢悬挑扣件式钢管脚手架的设计、搭设与拆除。
2. 脚手架搭设、拆除作业前，应根据工程特点编制专项施工方案，并应经审批后实施。
3. 搭设高度24m及以上的落地式钢管脚手架工程属于危大工程，应编制专项施工方案。

二、立杆与基础
1. 每根立杆底部宜设置底座或垫板。
2. 脚手架立杆基础应平整夯实，地基承载力应满足要求（夯实后承载力不宜小于100kPa）；垫板应采用长度不少于2跨、厚度不小于50mm、宽度不小于200mm的木垫板。
3. 脚手架必须设置纵、横向扫地杆。纵向扫地杆应采用直角扣件固定在距钢管底端不大于200mm处的立杆上；横向扫地杆应采用直角扣件固定在紧靠纵向扫地杆下方的立杆上。
4. 立杆接长除顶层顶步外，其余各层各步接头必须采用对接扣件连接；相邻立杆的对接扣件不得在同一高度内错开。
5. 单排脚手架搭设高度不应超过24m；双排脚手架搭设高度不宜超过50m。

三、连墙件
1. 脚手架连墙件设置的位置、数量应按专项施工方案确定。
2. 连墙件应靠近主节点设置，偏离主节点的距离不应大于300mm。
3. 应从底层第一步纵向水平杆处开始设置连墙件，当该处设置有困难时，应采取其他可靠措施固定。
4. 连墙件应优先采用刚性连墙件，与建筑结构可靠连接；连墙杆应呈水平设置。
5. 开口型脚手架的两端必须设置连墙件，连墙件的垂直间距不应大于建筑物层高，且不应大于4m。
6. 连墙件中的连墙杆或拉筋宜呈水平设置，当不能水平设置时，与脚手架连接的一端应下斜连接，不应采用上斜连接。

四、剪刀撑与横向斜撑
1. 双排脚手架应设剪刀撑与横向斜撑，单排脚手架应设剪刀撑。
2. 每道剪刀撑跨越立杆的根数宜按规范确定；剪刀撑斜杆与地面的倾角应在45°~60°之间。
3. 高度在24m及以下的单、双排脚手架，外侧立面两端各设置一道剪刀撑，并应由底至顶连续设置；中间各道剪刀撑之间的净距不应大于15m。
4. 高度在24m以上的双排脚手架，应在外侧全立面连续设置剪刀撑。

五、脚手板与作业层
1. 脚手板应铺满、铺稳，铺实；作业层脚手板应铺满、铺稳，离墙面120~150mm。
2. 作业层端部脚手板探头长度应取150mm，其板长两端均应与支承杆可靠地固定。
3. 作业层、斜道的栏杆和挡脚板均应搭设在外立杆的内侧；上栏杆上皮高度应为1.2m，挡脚板高度不应小于180mm，中栏杆应居中设置。

六、搭设与拆除
1. 搭设流程：立杆→纵向水平杆→横向水平杆→连墙件→剪刀撑。
2. 底座、垫板均应准确地放在定位线上。
3. 拆除作业必须由上而下逐层进行，严禁上下同时作业；连墙件必须随脚手架逐层拆除，严禁先将连墙件整层或数层拆除后再拆脚手架。
4. 拆下的杆件、扣件、脚手板等材料，应采用传运或袋装方式传递，严禁抛掷。

七、检查与验收
1. 每搭设完一步脚手架后，应校正步距、纵距、横距及立杆的垂直度。
2. 脚手架立杆垂直度偏差不应超过架高的1/150（且符合规范允许偏差表要求）。
3. 扣件螺栓拧紧力矩应为40~65N·m，且不应小于40N·m。
4. 脚手架应在下列阶段进行检查验收：基础完工后及脚手架搭设前；作业层上施加荷载前；每搭设完6~8m高度后；达到设计高度后；遇有六级大风与大雨后；寒冷地区开冻后；停用超过一个月。
5. 旧扣件使用前应进行质量检查，有裂缝、变形的严禁使用，出现滑丝的螺栓必须更换。

八、使用要求
1. 作业层上的施工荷载应符合设计要求，不得超载；不得将模板支架、缆风绳、泵送混凝土和砂浆的输送管等固定在脚手架上。
2. 严禁悬挂起重设备。
3. 在脚手架使用期间，严禁拆除下列杆件：主节点处的纵、横向水平杆，纵、横向扫地杆，连墙件。
4. 六级及以上大风和雾、雨、雪天气时应停止脚手架搭设与拆除作业。
